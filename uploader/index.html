Lofi Forecast Uploader

A private publishing tool for the Lofi Forecast YouTube channel

Lofi Forecast Uploader is a small, private command-line tool used only by the owner of the Lofi Forecast YouTube channel (@LofiForecastHK). It uses the YouTube Data API (YouTube API Services) to upload the channel's own original lofi music videos to that one channel, set their title, description, category and thumbnail, and add them to the channel's own playlists.

  • It is not a public app. There are no sign-ups and no other users.
  • It works only with the owner's own YouTube channel, authorized with Google OAuth 2.0.
  • It does not collect, sell or share anyone's personal data, and it does not show YouTube data to anyone else.

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service.
