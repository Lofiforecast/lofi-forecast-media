Privacy Policy: Lofi Forecast Uploader

Last updated: 1 October 2026

Lofi Forecast Uploader (the "Tool") is a private tool run by the owner of the Lofi Forecast YouTube channel (@LofiForecastHK). It is used only by that owner to publish the channel's own videos. It has no other users.

YouTube API Services

The Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

What information the Tool accesses

When the channel owner signs in with Google OAuth 2.0, the Tool asks for these permissions:

  • youtube.upload: to upload videos and custom thumbnails to the owner's channel.
  • youtube: to create the owner's playlists, add the owner's videos to them, and confirm which channel is authorized.

The Tool uses the API only to: upload a video file the owner made; set its title, description, tags, category, privacy setting and "made for kids" setting; upload its thumbnail; create a playlist on the owner's channel and add videos to it; and read the owner's own channel ID, playlist list and the IDs of uploaded videos. The Tool does not read comments, subscribers, analytics, or any other user's data.

What is stored, where, and for how long

  • OAuth token: the access/refresh token is stored in a single file, readable only by the owner, on the owner's private computer. It is never shared with or sent to anyone except Google.
  • Upload log: a local file records the YouTube video IDs and playlist IDs the Tool created, so it does not upload the same video twice. The Tool does not store other API data. Any API data kept is refreshed or deleted within 30 days, as YouTube's Developer Policies require.
  • The Tool has no server, database, analytics, advertising, cookies or tracking.

Sharing

The Tool does not sell, rent, share or disclose any information to third parties.

How to revoke access and delete data

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After access is revoked, or on request, the stored token and upload log are deleted from the owner's computer within 7 days. Videos and playlists on YouTube can be managed or deleted in YouTube Studio.
